# OrangeHRM Manual Testing Project

## Project Overview

This project focuses on manual testing of the OrangeHRM web application. The objective was to understand the application functionality, prepare test scenarios and test cases, execute test cases, and document the actual results.

The project helped me gain practical experience in manual testing concepts and the Software Testing Life Cycle (STLC).

## Application Under Test

- **Application:** OrangeHRM
- **Application Type:** Web Application
- **Application URL:** https://opensource-demo.orangehrmlive.com/
- **Browser:** Google Chrome
- **Operating System:** Windows
- **Testing Type:** Manual Testing
- **Testing Approach:** Functional Testing
- **Test Level:** System Testing

## Modules Covered

The following modules were covered in this project:

1. **Login Module**
   - Valid and invalid login credentials
   - Mandatory field validation
   - Login error messages
   - Dashboard redirection
   - Access to protected pages

2. **Dashboard Module**
   - Dashboard page display
   - Dashboard widgets
   - Quick Launch functionality
   - Navigation and page display

3. **Admin Module**
   - User creation
   - User search functionality
   - User role validation
   - Password validation
   - User status filtering

4. **PIM Module**
   - Employee information display
   - Add employee
   - Mandatory field validation
   - Employee search
   - Edit employee details
   - Delete employee

## Testing Activities

- Reviewed application functionality.
- Prepared a Test Plan.
- Identified test scenarios.
- Designed and documented test cases.
- Executed manual test cases.
- Compared actual results with expected results.
- Recorded execution status and observations.
